## 3. FSHD 事件语义

| 类别 | 原型例子 | 说明 |
|---|---|---|
| 确诊/遗传 | 基因确诊节点 | 仅记录日期和来源，不推断严重度 |
| 功能/器具 | AFO 配具交付 | 可作为已发生事件；不据此推断疗效 |
| 并发症筛查 | 眼底复查 | 计划状态来自建议原文；日期已过也不自动变已完成 |
| 讨论/待核/未知 | 数据状态预留 | 分开标记，不能合并为“计划” |

当前时间点事件；以后如支持日期区间，必须保留精度与真实起止信息。事件结构建议 `id/type/title/startDate/endDate/status/sourceRefs`，前端坐标只属图表投影。所有事件与指标相关性均不作因果解释。

## 4. 默认状态

| 项 | 当前默认 |
|---|---|
| 时间范围 | 近12月，近6月/全期可切换 |
| 缩放 | 100%，右端锚定全局最新日期（当前含计划事件日期） |
| 显示 | 事件、末点值、变化标注开启 |
| 固定详情 | 空；点测量或事件后固定 |
| 重播 | 首次进入、指标/范围/缩放改变及主动重播时播放；事件详情重绘不重播曲线 |
| 减少动效 | 曲线终态、点和事件立即显示 |
