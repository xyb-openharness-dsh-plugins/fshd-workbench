## 3. 对工作台资源功能的需求补强

1. **资源卡按任务筛选**：病友支持 / 基因诊断咨询 / 儿童评估 / 康复与辅具 / 医保救助 / 遗传沟通 / 研究咨询；同时展示地区和语言。FSHD 专病证据与一般罕见病服务分开显示。
2. **“看到资源”闭环到“准备咨询”**：详情含证据、官网入口、最近核验日期、待问问题；可收藏到复诊准备、记录联系日期与回复、标记失效。首期只打开官方入口，不代挂号、自动传报告或发送邮件。
3. **资格未知保留未知**：救助卡记录项目原名、适用病种、地区、申请期、费用类型、申请材料与回复来源；不能凭 FSHD 在罕见病目录内就显示“可申请成功”。医保、残疾证与公益救助是不同制度，各自追踪。
4. **来源与核验分层**：`官网说明 / 原始研究 / 团队自述 / 用户反馈`独立字段；用户记录“联系成功”只更新个人联系日志，不自动改为医学能力验证。研究中心是否招募与是否开展普通门诊分别记录。
5. **私密资料保护**：遗传报告、家系和家庭经济材料默认留本机；用户主动选择导出哪些材料，预览后自行提交。公共资源卡不能混入私人联系方式和其他病友病历。

建议记录稳定机构 ID、原名与别名、机构类别、服务地点/语言、疾病特异证据、服务能力声明、预约/申请入口、限制条件、证据 URL 与发布日期/核验日期、待复核项、失效状态。机构事实与患者自己的联系/申请进度分开存储。

## 4. 尚未验证，不能在原型中写成已接通

- 国内各院现行挂号入口、年龄边界、FSHD1/2 复杂样本检测范围、收费及周期，未做电话核验。
- ICF 各项目对 FSHD 的资金援助适用范围、名额和个人资格，未取得书面回复。
- FSHD-China 当前活动排期、入群方式、组织登记信息，未取得组织确认。
- 海外研究中心是否接受中国患者、能否远程意见、翻译/保险和跨境费用，未核实。
- 国内跨科转诊（呼吸、眼底、听力、脊柱、遗传生殖）不能只凭神经科有 FSHD 研究就写成 MDT 已接通。

这些空白应成为“咨询前核对清单”，不妨碍先提供来源明确的公开信息和个人准备工具。
