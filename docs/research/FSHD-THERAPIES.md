# FSHD 药物、技术与可及性研究稿

核查日：2026-10-18。范围：面肩肱型肌营养不良症（FSHD）；优先公司原始公告、监管注册和临床指南。本文提供需求设计证据，不替代个人诊疗建议。没有检索到的批准、价格和中国试验点均保留为“未核实”，不以空白推导绝对不存在。

## 1. 可直接用于需求的结论

目前临床照护以康复、辅具、疼痛与呼吸管理及精选患者手术为基础；创新治疗仍处研究阶段。2026 年 9—10 月的开发者资料仍明确 FSHD 无获批疾病修饰疗法。[1][2][3] 这意味着工作台应同时帮助患者处理“今天能做什么”和“哪些研究可能与我有关”，不能把新药管线做成可购买药品目录。

**最需要防止的过期信息有三类：**losmapimod 不是已验证有效或即将上市的口服药；emugrobart/GYM329 的 FSHD 开发已停止；EPI-321 已进入人体试验，不能继续写成纯动物研究，但也不能写成一次注射治愈。[3][4][5]

## 3. 目前能够讨论的临床照护技术

以下是 FSHD 指南/专家综述支持的照护类别，不是给所有患者统一使用的处方。[14][15]

| 场景 | 可讨论的照护技术 | 工作台应支持的结果 |
| --- | --- | --- |
| 足下垂、绊倒或走路吃力 | 个体化物理治疗、适当运动及踝足矫形器/移动辅具评估 | 准备症状、跌倒史和就诊问题；记录辅具适配与复查，不能只推荐商品 |
| 肩胛翼状、抬臂和穿衣受限 | 康复/作业治疗；精选患者可评估肩胛固定术 | 记录具体任务受限与目标，准备手术获益/风险问题；手术并非阻断疾病进展 |
| 疼痛和疲劳 | 疼痛评估、物理治疗、按医嘱药物及日常活动调整 | 记录部位、强度、诱因、活动影响及复诊摘要 |
| 呼吸受累或睡眠问题 | 肺功能评估、专科转诊，必要时通气支持 | 把已确认的呼吸随访任务与一般锻炼提醒分开；异常触发就诊 |
| 闭眼不全、听力或视网膜问题 | 眼保护、眼科/听力评估与相应治疗 | 根据症状、发病年龄和临床风险管理检查，不一律宣称所有人必须相同检查频率 |

中国能否在某医院接受上述具体服务、等候时长、跨省就医手续及报销比例，本轮未完成逐院核查，均不能预填“可做”“医保报销”。无获批特效药也不等于无可开展的照护。

## 4. 可及性需求应怎样落地

1. **先判断是什么路径。**每条资源区分常规诊疗、临床试验、登记/自然史研究、实验室研究和商业广告。中国 CF1R 登记及 NCT06517498 生活负担调查均不能当新药试验名额。[16][17]
2. **资格只做初筛。**可提取年龄、FSHD1/FSHD2、遗传确认、可行走状态、肌力/严重度、既往研究用药和所在地。资料不完整显示“需补充”，不推断符合资格；最终由中心判断。
3. **可核查、能行动。**每卡至少保存来源 URL、公告/注册更新时间、核查日期、地区/中心、招募状态、证据终点、已知风险/未知项和下一次询问清单。
4. **费用必须拆分。**药费、试验检查、交通、住宿、陪护、误工和保险/补贴各自记录；无正式价格则显示“未公开/未核实”，不能用其他病种基因治疗价格估算 FSHD 定价。
5. **变更可追溯。**药物更名保留同一稳定 ID；来源状态冲突显示历史和最新证据，不因抓取到旧的招募页而覆盖停止开发公告。每次查询不能自动把候选更新写成已核实事实。

## 5. 检索边界与未决事项

- 直接访问部分 ClinicalTrials.gov 页面仅返回动态壳；本稿对相关阶段采用开发者正式公告和日本政府注册交叉核查。点击注册链接仍应在正式上线前补全结构化快照。
- 本轮 NMPA/中国试验登记网页检索未找到上述候选的中国获批或大陆试验中心可靠记录；这不是数据库全量穷尽，结论只写“未核实”。
- EPI-321、del-brax 等新数据部分为公司/会议披露，缺乏完整同行评审和长期临床结局；宣传用语“疾病修饰潜力”“首次”不应作为患者疗效承诺。
- 本稿不评估个体治疗适宜性，不将干细胞、商业“基因修复”、保健品或高价自费项目收为已验证 FSHD 治疗。
