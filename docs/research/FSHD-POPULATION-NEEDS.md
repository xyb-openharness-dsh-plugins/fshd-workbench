# FSHD 患者规模与患者需求证据稿

调研截止：2026-10-18；检索日：2026-10-18。范围：FSHD 患者及家属，优先中国；继承 `docs/BRIEF.md` 与已确认 `docs/SCENARIOS.md` 的全程管理方向。本文是需求研究证据，不是患者诊疗建议；需求映射为研究建议，不自动改变已确认优先级。

## 1. 患者规模：必须分开三种数

| 口径 | 核验结果 | 可用于什么／不可用于什么 |
| --- | --- | --- |
| 国际人群患病率 | 2014 年荷兰三来源捕获再捕获研究，使用 2001–2010 年登记，校正未登记有症状者，估算 **12/10万**；遗传确诊时代历史研究平均约 **5/10万**。[1] | 说明遗漏登记明显；不是全球统一真实患病率，也不能无条件套用中国。 |
| 全球组织估计 | FSHD Society 患者介绍仍列 **约87万人、1/8000**；其机构介绍页另用 **约100万人**。[2][3] | 是倡导组织规模估计，页面无明确统一估算基准日；两页不可拼成确诊人数或增长率。 |
| 中国研究捕获确诊数 | 2022 年发表研究回顾 2001–2020 年：**997 名基因确诊 FSHD1、620 个家系**；以 2010 普查人口为分母，得到 **0.75/百万人**。作者提示漏诊、地理差异与检测可及性限制。[4] | 是历史研究捕获规模，包含不同表现的携带者；不是截至2026年的全国患者总量，也不覆盖全部FSHD2。不能据此说“中国只有约1000人”。 |
| 中国潜在人群：情景外推 | 以国家统计局2025年末 **14.0489亿**人口为分母[5]；假定国际 **5–12/10万**在中国成立，则约 **7.02万–16.86万人**。 | 仅用于需求规划的量级敏感性分析；**不是中国实测患病率、官方估计或置信区间**。跨人群外推有遗传结构、年龄、诊断条件及调查方法差异。 |

量化复核：`1,404,890,000 × 5 / 100,000 = 70,244.5`；`× 12 / 100,000 = 168,586.8`。统一向“万人”保留两位小数，避免虚假精确。全球如仅做可复核情景，以联合国2024年82亿人口[6]乘上述5–12/10万，得到约41万–98.4万；这是**2024人口情景**，不能写成2026确诊统计，也不能与87万宣传估计当作同一测算。

没有找到可核验的截至2026-10-18中国全国完整患者登记总数。历史确诊数和情景估算间差距不能直接计算成“中国漏诊率”，因两者时间、人群定义与方法不同。

## 2. 患者角度的 Top 5：先呈现患者原始诉求，再映射产品

中国直接证据：Ji等2026-02-25发表的混合方法研究，在线调查时间为2024年3–10月，**263份有效问卷**（226本人填写、37家属代填）及**33名患者访谈**。通过患者组织网络招募，存在便利取样、数字可及性和自述偏差；不是全国随机抽样。论文明确归纳以下五类优先未满足需求，**未给出这五项的统一量化名次，编号仅供产品讨论**。[7]

| 五类诉求 | 研究支持 | 工作台可落实的动作与产物（设计推导） | 对应已确认场景 |
| --- | --- | --- | --- |
| 1. 盼望靶向药物、延缓进展 | 中国研究将药物获批作为核心未满足需求[7]；欧洲1147人调查中，31%选择停止进展为新疗法最重要结果。[8] | 收藏研究→核对阶段、数据、地区与核验日→形成“询问研究团队”的问题单。结果、注册状态、实际可及性分列。 | V9临床研究；不凭注册条目声称药物可买 |
| 2. 得到适合自己的辅助器具、维持独立生活 | 中国研究明确提及器具可及性[7]；PRISM-FSHD 328人调查中肩臂问题96.9%、活动受限94.7%。[9] | 按具体生活任务记录困难→留存医生/治疗师建议及器具→记录试用、维修和费用→带回随访；覆盖上肢、躯干、下肢，不只记录轮椅。 | V2功能＋V6康复器具；补“跌倒事件/损伤/发生环境” |
| 3. 可持续的心理支持 | 中国研究列心理支持；158名完成两心理量表者中，中重度焦虑48.8%、抑郁69.6%，**不是263人全体的诊断率**。[7] | 私密记录困扰→自选联系对象与已核验支持资源→记录是否获得支持。不开自动精神诊断、不把记录代替专业支持。 | V10心理与生活；建议入口常可找到，是否升优先级需纳入设计决策 |
| 4. 能继续工作或学习，减少收入中断 | 中国研究明确列就业机会[7]；欧洲调查报告能量不足影响想要的生活与工作。[8] | 记录任务限制与希望的调整→生成沟通清单→留存申请、回应和复盘。无职位推荐与雇佣结果承诺。 | V10生活就业＋V8费用救助 |
| 5. 更包容、无障碍的社会环境 | 中国研究列更友好社会环境[7]；欧洲患者把独立性及参与社会活动作为重要结果。[8] | 为具体出行建立无障碍需求清单→逐项核实通道、卫生间、陪同及交通→保留联系日期、待核实项与替代方案；不把地图POI当无障碍事实。 | V10生活＋V8资源 |

疼痛与疲劳应作为上述需求共同底座：PRISM-FSHD调查中疲劳93.8%、疼痛87.7%。[9] 所以既保留V4独立记录，也在“本次最想改善哪项生活任务”中允许关联疼痛和疲劳；避免要求患者每天填满长量表。

## 3. 对现有 list 的补充建议（不撤销既有确认）

1. **确诊档案继续P0**：中国患者调查平均诊断历时9.8年、误诊57%[7]，应保留“症状出现→首次就医→曾诊断→基因确诊”的来源时间线；记录“未做/未取得/待补报告”，不因缺字段堵住进入工作台。
2. **功能记录从肌群扩展到生活任务**：面/肩/臂/躯干/腿部可继续分区，另用洗头、穿衣、取高处物、起身、上下台阶、出门等患者自选任务描述变化。上肢功能独立性不能被步行能力遮盖；2024年患者向FDA专门进行了上身活动能力倾听会。[10]
3. **补跌倒记录**：欧洲患者调查63%报告曾跌倒[8]，支持记录发生日期、情境、损伤原文、是否就医、复诊问题；不由软件计算个人跌倒风险或自动训练处方。
4. **心理与生活应有首屏可达入口**：保持既定合并子页，避免只写成P2占位。是否整体提升优先级属于新的价值范围决策，原型中至少让使用者看见帮助入口并明确未接通项。
5. **并发症筛查保留，但不要声称四类检查所有人统一定期做**：眼、听力和呼吸的适用条件不同，应由用户保存医嘱/建议日期及来源；“未建议/待问医生”也为有效状态。GeneReviews提供分人群监测条件。[11]
6. **试验可及性增加患者成本信息**：欧洲调查最突出障碍是试验距离与副作用担忧[8]；条目应分列地点、往返次数、过夜、陪同、费用/补偿“有明确来源/待核实”，不自动判定入组资格。
