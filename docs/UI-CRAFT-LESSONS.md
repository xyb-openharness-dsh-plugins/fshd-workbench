## 0. 怎么读

每条固定四段：**现象 → 根因 → 做法 → 通用性**。
「通用性」只有三档：★ 通用可沉淀 / ☆ 半通用（要改写） / ○ 本项目特有（不搬）。

## 1. 字号与可读性

### 1.1 「大字」开关是半失效的

- **现象**：用户点「大字」，只有零散几处变大，按钮、卡片正文、标签纹丝不动。用户会判断"这功能没做"。
- **根因**：字号治理只做了一层——`body.large{--fs:16px}` 改的是基准字号，但组件里 100+ 处 `font-size:12px` 是**硬编码**，根本不读 `--fs`。
- **做法**：引入全局倍率 `--tz`，把所有 `font-size:NNpx` 机械替换成 `calc(NNpx * var(--tz))`；`:root` 给 `--tz:1`，大字档给 `1.15`。改完实测：按钮 12→13.8、卡片正文 13→15、标签 11.5→13.2，全部跟随。
- **通用性**：★ 通用。任何"字号可调"的工作台都会踩，且**改造是纯机械的**（一条正则），成本远低于收益。

### 1.2 字号档位不能作用到 SVG 图内文字

- **现象**：大字档下，图表末点标签互相重叠、事件标签顶出画布。
- **根因**：末点避让是按"固定字号 10.5px + 13px 最小行距"算的几何；字号一变，避让结果的坐标全错，而算法本身没跟着改。
- **做法**：`.chart .tick / .ev-label / .delta-tag` 显式写成固定 px，不参与 `--tz`。理由写进合同的偏离表：图内文字已随 SVG 整体缩放，视觉大小跟容器走，不跟档位走。
- **通用性**：★ 通用。**凡是有"标签避让 / 碰撞检测"的图，都别让字号参与全局缩放**，否则等于把几何参数改成了变量。

### 1.3 固定高度的卡片在大字档被裁

- **现象**：超大档下指标卡只显示半截内容，没有滚动条，也没有提示。
- **根因**：卡片 `height:186px` 写死，`overflow:hidden` 兜底，内容 237px 直接被吞。
- **做法**：`height:calc(186px * var(--tz))`。实测超大档 246px，六卡同高。
- **通用性**：★ 通用。**凡是给了固定高度 + overflow:hidden 的组件，都要在加字号档位时同步检查**。

## 2. 布局与信息密度

### 2.1 页面标题三层重复

- **现象**：一进看板看到「我的 FSHD 工作台 / 看板」→「看板」→「记录变化，准备下一次复诊。」三个大标题连着，第一屏全是标题，没有内容。
- **根因**：`eyebrow`（面包屑）、`page-head h1`（页面名）、`hero h1`（主张）三层各自都有理，叠在一起就变成三层标题。
- **做法**：删 `eyebrow`；看板页干脆不渲染 `page-head`，直接让 hero 主张当唯一主标题（导航高亮已经说明"你在哪一页"）。
- **通用性**：★ 通用。规则可以写成一句：**同一屏只允许一个 h1 级标题；面包屑与页面名二选一。**

### 2.2 12 项导航平铺像一堵墙

- **现象**：左侧导航 12 行等高堆着，没有节奏，扫读要靠逐行念。底部还压着三行小字，更堵。
- **根因**：导航按"功能清单"排序，没有按"用户任务"分组，间距又只有 2px。
- **做法**：分 4 组（概览 / 病程与记录 / 支持与准备 / 设置），组间 15px、组内 1px，加 11px 小标题（letter-spacing 1.3px、opacity .85）。底部三行小字压成一行「画像稿 · 未签认」，用虚线与导航分隔。
- **通用性**：★ 通用。**超过 8 项的导航一定要分组**，否则视觉上等于没有信息层级。分组名用动词性任务词（病程与记录），不要用系统词（模块管理）。

### 2.3 说明文字堆在控件之间

- **现象**：一图秀左侧 rail 从"最多 4 条…"到"右端锚定…"到一整段"口径"，控件被说明切碎，一屏里文字比控件多。
- **根因**：把"边界情况说明"当成常驻文案，写在主流程里。
- **做法**：三档处理——
  1. 行为已经自解释的（勾第 5 个会被拒绝），**直接删**；
  2. 需要时的补充（缩放 40% 是什么意思），进 `title` / `aria-label`；
  3. 解释性长文（归一化口径），折进 `<details>`，标题只留两个字。
- **通用性**：★ 通用。可写成规则：**界面上常驻的说明句，必须能回答"用户此刻要做什么"；不能的，折叠或删除。**

### 2.4 分组标题与卡片自带分类重复

- **现象**：指标卡区域「检验 1 项」分组标题下面只有一张卡，卡片正面又写着「检验」；换个分类再来一遍。标题比卡片还占地方。
- **做法**：去掉分组标题，所有卡片进一个 `auto-fill` 网格，分类由卡片正面的小标签承担。
- **通用性**：☆ 半通用。分组在"数量足够多、需要跳读"时仍有价值；判据是**单组卡片数 ≤ 2 就别分组**。

## 3. 图表与标签几何

### 3.1 图表字号随容器缩小

- **现象**：980 宽的 viewBox 塞进 700px 容器，缩放比 0.71，11px 的轴标签实际显示 7.8px。
- **根因**：`width:100%` + 固定 viewBox，所有内部尺寸等比缩小；设计时按画布尺寸校的字号，在容器里不成立。
- **做法**：用 `getBoundingClientRect()` 反算实际显示字号（`11 × 容器宽/980`），低于 9px 就提高画布字号或减小 viewBox 宽度。本项目最终保持 980，靠"容器 ≥ 940"成立。
- **通用性**：★ 通用。**SVG 字号要按"缩放后"验收，不能按源码数值验收。**

### 3.2 跨年时间轴不标年份

- **现象**：轴上是 `12月 2月 4月 6月 8月 10月`，看不出跨了年；用户以为是同一年内的十个月。
- **做法**：只在**首个刻度**和**每年 1 月**标 `2025年12月` / `2026年1月`，其余仍 `2月`。既说清跨年，又不会让刻度变成一串数字。
- **通用性**：★ 通用。判据：`t0.getFullYear() !== t1.getFullYear()` 才启用。

### 3.3 只有水平网格，时间轴没有"刻度感"

- **现象**：五条水平线只能读"值高低"，读不出"这个点在几月"。
- **做法**：在每个月份刻度处加一条竖向淡网格（`#f4f9f6`，几乎不可见但能对齐）；泳道与数据区之间加一条虚线分隔。
- **通用性**：★ 通用。竖向网格要**比横向更淡**，否则会与数据线抢注意力。

### 3.4 事件引线穿过数据区

- **现象**：事件竖虚线一路画到图底，视觉上像在暗示"这个事件导致了后面的数值变化"。
- **做法**：引线止于 `plotTop - 9`，泳道单独占顶部 3 行，不侵入数据区。
- **通用性**：★ 通用。医疗场景尤其要守——**时间上的先后不等于因果**，图形不能替用户下这个判断。

### 3.5 图例三段式冗余

- **现象**：每条图例写「末值 412 U/L｜全期 318–412｜较上次 +6.7%」，4 条占两行，第一屏被图例吃掉。
- **做法**：压成「名称 + 数值 + 变化」三段，去掉"末值/全期"字样（位置本身已经表示"末值"），全期范围交给卡片背面与复诊表。
- **通用性**：★ 通用。图例的职责是**认色**，不是给完整统计。

## 4. 状态与交互

### 4.1 翻卡背面用文字重复正面

- **现象**：卡片翻过去是一段说明文字，用户翻完感觉"白翻了"。
- **做法**：背面放**该指标自己的迷你折线**（首末日期 + 全期范围），只有 1 次记录时写明「只有 1 次记录，暂不连线」，不画水平假线。
- **通用性**：★ 通用。翻转必须给"正面放不下的新信息"，不能是正面的解释。

### 4.2 重播会重置状态

- **现象**：点"重播趋势动画"后，筛选、翻卡、滚动位置全回去了。
- **做法**：重播只重建 `#chartWrap` 的 SVG，不改 state；动画用独立的 `animationRunId` 触发重启。
- **通用性**：★ 通用。

## 5. 验证方法（这部分比结论更值钱）

| 做法 | 为什么 |
| --- | --- |
| 用无头浏览器跑**逐页断言**而不是只看截图 | 截图看不出"标签越界 3px""翻卡后另外 5 张也翻了"这类问题 |
| 溢出判据用 `body.scrollWidth`，不用 `documentElement.scrollWidth` | 后者在 `container-type` 容器下会把**内部滚动内容**算进去，本项目因此误报 534px（实际 390，`scrollLeft` 设 300 仍为 0） |
| 三档字号 × 12 页 × 1440/390 全矩阵跑 | 只测一档一定漏；超大档是最容易撑破的 |
| 断言写成"改前 / 改后对比"（如关事件前后 `path[d]` 必须完全相同） | 防止"重绘把别的状态也改了" |
| 记录**偏离**，不静默改 | 每条偏离写清"参照的规范 / 实际做法 / 理由 / 谁批准的"，否则下一个人会当 bug 改回去 |

## 6. 本项目特有（不进脚手架）

- **FSHD 无治疗周期**：事件泳道只有"确诊 / 器具 / 筛查"时点事件，没有治疗 bar；这套语义不能套到肿瘤工作台。
- **基因报告只做抄录**：D4Z4 重复数用大号数字做锚点，但页面不出现严重度、外显率、预后判断——这条属于医学边界，不是排版经验。
- **私密默认**：家系记录、心理与生活默认私密，卡片底色用紫色体系区分，不进导出、不进看板摘要。
- **画像预置数据**：三组演示画像共 55 个指标点，是为了"图表有内容可看"，不属于产品能力。
- **并发写入导致的白改**（工程环境问题）：同目录被另一会话写入时，`Edit` 的 old_string 可能匹配到拼接后的内容，把函数改坏。**判据是 `node --check` 立刻报错**；恢复办法是从 `git show HEAD:<file>` 取回整个函数再重做替换，不要逐行修。
