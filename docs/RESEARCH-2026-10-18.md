# 小飞侠 FSHD · 需求调研与实施起点

版本：研究 v1.0；核查日 **2026-10-18**。本轮“list”指 [SCENARIOS](SCENARIOS.md) 的 V1–V11。中国患者优先，国际研究与照护资源补充。继承已确认品牌、场景排序与V10子页归属；没有开展本项目患者访谈、临床审核、真实预约或资格核验。

## 1. 患者规模：全国总量仍未知

国际研究常用约5–12/10万的患病率量级。中国历史研究在2001–2020年捕获997名基因确诊FSHD1、620家系，**不是全国现患总数**。若仅将国际范围乘2025年末中国大陆人口14.0489亿，得到约 **7万–17万**；这是规划情景，既非实测也非置信区间。全球患者组织约87万至100万的表述同样是估计，各页基准不同，不能当登记统计或增长趋势。原始研究、计算与局限见[规模与患者需求证据稿](research/FSHD-POPULATION-NEEDS.md)。

## 2. 药物和技术：常规照护与研究分轨

| 路径 | 核查结论 | 患者实际可及性 |
| --- | --- | --- |
| 现有支持性照护 | 康复/作业治疗、适配器具、疼痛管理、呼吸支持，以及特定患者肩胛固定等；不是统一处方 | 需专科评估；逐院服务、费用和报销仍要咨询。无疾病修饰药不等于没有治疗与照护 |
| del-brax / AOC1020 | III期进行中；已有生物标志物数据 | 在研、未获批；中国中心/批准/费用未核实 |
| EPI-321 | I/II期；首6例六个月开放标签初步结果，全试验12例已入组 | 不展示为当前可报名；小样本结果不等于长期有效或治愈 |
| SRP-1001 / 原ARO-DUX4 | I/II期，2026年公司披露早期人体数据 | 在研，功能获益与中国可及性待核实 |
| DYNE-302 | 2026年IND放行，进入临床启动阶段 | IND不等于上市，也不能替代首例给药证据 |
| apitegromab | FSHD II期FORGE于2026年开始给药 | 其他病种结果不能当FSHD疗效；中国路径未核实 |
| losmapimod / emugrobart | 前者III期失败后暂停；后者2026年停止FSHD开发 | 保留负面结果，避免旧管线页造成仍可参与的误解 |

上述动态状态的逐项官方公告、事件日期、注册号和访问限制见[药物技术与可及性证据稿](research/FSHD-THERAPIES.md)。核心来源示例：[Novartis，2026-06-11](https://www.novartis.com/us-en/news/media-releases/novartis-delpacibart-braxlosiran-del-brax-phase-iii-study-facioscapulohumeral-muscular-dystrophy-fshd-meets-primary-biomarker-endpoint)、[Epicrispr，2026-10-05](https://epicrispr.com/epicrispr-reports-positive-six-month-data-at-the-world-muscle-society-meeting-demonstrating-increased-lean-muscle-volume-and-muscle-strength-in-fshd-patients-treated-with-epi-321/)。公司公告与同行评审分开；并未穷尽核验全球监管数据库，不以未搜到推断绝对不存在。

## 3. 患者角度 Top 5 与产品可做的事

中国2026年发表的患者研究（2024年调查，263份问卷＋33人访谈）提供直接证据。下列为五类突出诉求，**没有统一量化1–5名次，不能称全国排名**。[期刊研究](https://doi.org/10.1186/s41687-026-01026-z)

| 患者诉求 | 工作台提供的具体帮助 | 对应list |
| --- | --- | --- |
| 有可获得、可负担的靶向治疗 | 收藏线索→分辨注册/结果/获批→核实地区、中心、往返成本与补偿→咨询问题单 | V9；软件本身不能提供药物 |
| 合适的辅助器具与独立生活 | 记录生活任务困难及不对称→留存专业建议/器具适配→记录费用、维修、体验与跌倒→复诊回顾 | V2/V6 |
| 持续心理支持 | 私密记录希望获得的支持→选择公开支持渠道→保存联络与是否得到支持；不替代专业服务 | V10 |
| 就业与学业机会 | 任务限制→希望的调整→沟通清单→回应与复盘；不承诺岗位 | V10/V8 |
| 包容社会环境与无障碍 | 为一次出行列需求→核实通道/交通/卫生间/陪同→保存日期及替代方案；未核实不标可达 | V10/V8 |

确诊档案、疼痛疲劳、筛查、遗传咨询和复诊准备仍是已确认的管理基础，不因这份五项列表而删掉。五项诉求不是五个导航页。建议把V10由P2提前P1、在首页保留入口；**优先级尚未变更**。

## 6. 证据缺口与后续验证

- 中国完整患者登记、当前诊断成本/等待时间、各地医保救助资格：未取得全国一致证据。
- 在研项目的最新名额、中国中心和费用/补偿：需逐中心核验；观察登记不等于药物试验。
- 患者组织样本、国外调查、公司公告各有偏差；外推和患者优先级不冒充本项目访谈。
- 专业筛查计划、复杂分型与遗传解释需临床审核；不自动从基因数值生成患者结论。
- 研究交叉检查已完成并修订4项：登记/招募区分、生活支持闭环、参与负担字段、组织主体区分。不是临床审核或独立设计签认。

## 7. 工具与 FSHD 的关系（Khub / OpenRare，2026-10-18 补充）

来源：Khub 社区公众号《确诊后，我让AI读完了自己的基因组》（2026-08-27）、OpenRare 项目组公众号（2026-08-30）、「无界对话舱」活动海报（病痛挑战基金会 × Khub 罕见病社区 × CHANCE 亨廷顿社区 × 南科未来科学院）。

- **关系链条**：FSHD 确诊依赖基因检测（D4Z4），患者手里常有 WGS/VCF 原始数据但没有解读能力。Khub（FSHD 病友艾力亚尔发起的患者共创社区）提供 AI×基因解读的开源脚本、单病种知识库与患者×技术活动；OpenRare 是其技术方向的基因辅助诊断 Agent 基础设施（中文 HPO 标准化、多源证据、确定性排序、本地部署、链路不持久化基因数据）。
- **与工作台的关系 = 互补不重叠**：工作台坚持「基因报告只抄录不判读」；患者用 AI 工具产生的个人基因组解读（如药物基因组学、补剂建议）一律定位为「待医生复核的线索」，只存来源与原文位，不进确诊档案事实区。资源页已收录 Khub（患者组织类）与 OpenRare（渠道/工具类），均标注未核实与"最终诊断由医生做出"。
- **产品含义**：V11（资料白话解读）与「我的确诊」页的 AI 线索位为这类工具留接口；帮助患者把 26 份报告式的探索结果**结构化留痕**，而不是替代其判断。
