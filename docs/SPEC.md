## 1. 目标与非目标

**目标**：让 FSHD 患者（及家属照护者）回答六个问题：

1. 我的确诊依据是什么？基因报告说了什么、怎么一步步确诊的？（**确诊**）
2. 我现在的功能状态：哪些做不了了、和半年前比变了吗？（**功能**）
3. 该防的并发症（眼/听力/呼吸/脊柱），该查什么、上次何时、下次何时？（**筛查**）
4. 疼痛和疲劳怎么记录、复诊时怎么说清楚？（**症状**）
5. 生活上的事——支具、救助、医保、就业学业——进行到哪一步？（**生活与资源**）
6. 遗传的事（家系、50%、新生突变）怎么跟家人谈？（**遗传**，默认私密）

**非目标**：不做诊断、不判读基因报告临床意义、不预测进展/外显、不给康复处方或用药建议、不做病友匹配社区、不写"等待治愈"叙事。

## 2. 产品立场

继承家族 9 条立场（见结直肠癌 SPEC §2），FSHD 补充：

10. **尚无获批疾病修饰药，不等于没有支持性治疗**：工作台全部价值在"现在能做什么"——功能维护、并发症早筛、症状记录、资源对接。
11. **基因报告只做结构化抄录**：D4Z4 重复数、4qA/4qB 单倍型、检测方法（Southern Blot/分子梳/OGM/qPCR）只存原文与数值位，不做"严重/轻微"判读。
12. **遗传信息默认私密**：家系成员、家属检测状态默认不进导出，本人显式开放才变。
13. **研究线索不是治疗承诺**：在研药物一律标注"研究性干预，尚非获批治疗"；注册节点（IND/获批临床）与临床结果（FSHD 功能终点、患者报告结局和安全性等）分开显示，无公开数据时明写"目前无公开临床疗效数据"。

| 疼痛与疲劳 | 疼痛部位/触发/程度、疲劳模式记录；趋势图（记录用，非判读） | 慢性症状为主角（肿瘤工作台无） |
| 检查与指标 | CK（保留报告原值、单位及参考范围，不内置个人结果解释）、肌电图、其他报告；MinerU 导入→候选→核对 | 复用家族导入链路 |
| 病情一图秀 | 确诊节点 + 功能事件（分类）+ 筛查结果（分类）混合序列 | 包含康复、器具、支持性治疗及研究参与事件；不默认设疾病修饰药物疗程 |
| **医保与资源（专属一级模块）** | 慢特病门诊申请留痕、残疾证办理进度、罕见病救助项目状态（病痛挑战基金会等）、患者组织与专家资源档案 | 罕见病特有（肿瘤工作台无） |
| 心理与生活 | 当下感受（viewpoint，标"不是医生结论"）/ 身体形象与社交（面部表情误解、病情披露时机）/ **学业与就业、独立生活（子页）** | V10 并入子页（已确认） |
| 复诊准备 | 神经内科随访节奏 / 就诊准备（报告+功能变化+问题清单汇总）/ **遗传沟通材料（联动我的确诊）** | 遗传沟通入复诊 |
| 临床研究 | 在研管线追踪（Avidity、EpiCRISPR 等，**附药物卡片四段式**）、试验线索（CT.gov）、入组问题 | 注册节点≠临床结果 |
| 设置 | 全局设置页（目录/解析凭据/参考包/私密默认/关于） | 同骨架 |

### 明确不做

进展/外显率预测、康复训练处方、辅助器具品牌推荐、救助资格判断、残疾证代办、"即将上市"表述、病友匹配。

## 7. 风险

- **"无治疗"题材易滑向励志叙事或绝望叙事** → 文案红线检查（禁"等待治愈/放弃希望"），定调条用中性事实句。
- 误诊经历留痕可能引发情绪 → 心理支持联动入口 + 记录可标私密。
- 遗传话题敏感 → 默认私密 + 术语卡中性化 + "完全跳过不填"始终可用。
- 医保/救助信息时效性 → 每条标来源与"最后核对日期"，过期标"未核实"。
- 研究线索被当成治疗希望 → A8 强制分列 + 药物卡片四段式含"目前无公开临床疗效数据"位。

研究总览：[RESEARCH-2026-10-18.md](RESEARCH-2026-10-18.md)。研究不是用户访谈或临床审核。下列事实纠错用于本轮探索稿；原有 P0/P1/P2 与 V10 归属继承，优先级调整仅列建议。

| ID | 触发 → 动作 → 产物 | 字段/交互 | 可观察验收 |
| --- | --- | --- | --- |
| R1 治疗可及性 | 听到新药 → 分别核对监管、试验、结果及地区 → 可带去咨询的问题卡 | intervention_type、regulator、jurisdiction、approval_status、trial_id、phase、recruitment_status、sites、visit_count、overnight_stays、caregiver_needed、travel_cost、lost_work_cost、compensation_status（均可未知）、publication_date、checked_on、source_url；未知不补成无/有 | 参与负担与补偿未知时逐项显示“待咨询”；同一卡能显示“已有早期数据”且“未获批”；失败/终止项目仍保留；无中国中心证据时明写未核实 |

| R3 支持性干预 | 患者接受康复/器具/疼痛处理等 → 记录专业来源和体验 → 复诊摘要 | 干预名称、目的、开具方、日期、费用、原文建议、本人体验（非疗效判断） | 康复/器具/支持性治疗可入时间线；“无药”不屏蔽管理记录；不生成处方或产品推荐 |

| R7 患者五项诉求 | 查阅五项证据 → 跳到现有模块 → 保存行动 | 靶向药可及性/器具/心理/就业/社会环境映射 V9/V6/V10/V10/V8+V10 | 心理支持：记录希望联系的支持者及联系结果；就业：保存任务限制/希望调整/对方回应清单；无障碍：保存地点/待核条件/联系日期/替代方案；三者均能新增→保存→回顾，默认私密；五项均可找到入口和可完成动作；保持 V10 原子页；将首页提升为常显入口列“建议”，不得伪造用户确认 |
