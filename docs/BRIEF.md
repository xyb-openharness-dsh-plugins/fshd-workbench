# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：FSHD（面肩肱型肌营养不良）患者及家属照护者；含青春期/成年早期确诊者、面临遗传咨询与生育决定的家庭；患者组织志愿者协作使用

场景：基因检测确诊档案（D4Z4/4qA/ Southern Blot/OGM）与误诊经历留痕；面肩肱腹下肢功能变化与康复记录；足下垂AFO、腰背支具、轮椅等辅助器具档案；Coats眼/听力/呼吸/脊柱并发症筛查节奏；疼痛与疲劳管理；学业就业与独立生活；慢特病医保与罕见病救助；家属遗传沟通（默认私密）

核心流程：
1. 选择本机资料目录并导入基因检测/肌电图/眼科听力呼吸检查报告
2. 核对候选信息，建立确诊依据档案与家系记录
3. 记录功能变化、康复训练与辅助器具使用
4. 整理并发症筛查节奏与疼痛疲劳趋势
5. 生成复诊准备与遗传沟通材料

完成结果：得到来源可追溯、可核对的个人病程档案：确诊依据档案、功能变化记录、辅助器具清单、并发症筛查节奏与结果、疼痛疲劳趋势、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
