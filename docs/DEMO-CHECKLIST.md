## F. 本轮（2026-10-19）改了什么（用户三条反馈的处置）

1. **3D 反转折线图没体现** → 指标卡背面换成 `sparkline`（200×44 迷你折线 + 首末日期 + 末值 + 全期范围）；只有 1 次记录时写「暂不连线」，不画假线。
2. **确诊页文字堆积** → 用 taste 技能重做：情绪=清晰理性，主基因=瑞士平面/包豪斯（栅格、四级字号、单一强调色、flat 细线、52px 大号数字锚点），辅基因=中国画留白（原文与问题清单折进 `<details>`）。实测确诊页正文 480 字符（原为三段密集卡）。
3. **一图秀内容太少 / 缺指标选择与对比** → 画布换成与小畅宝一致的 980×420 + 单调三次插值；指标从 1 项扩到 6 项 × 3 档案（林晓飞 23 点 / 周航 9 点 / 陈静 23 点）；新增 rail（≤4 选择、分组、时间窗、缩放、口径）、图例（末值 + 全期范围 + 变化）、事件标签联动、重播按钮。
4. **附带修复**：AI 面板掉到左下 → 栅格改 `--pane` 变量 + `with-pane` 类，实测面板位于 main 右侧（mainRight 997 / paneLeft 1003）。
